# <span style="color:#d4af37; font-size:1.3em; text-shadow: 0 0 10px #d4af37;">游戏背景</span>

命案出现后，<span style="color:#a855f7;">预备魔女</span>们前往现场，搜集证据。

在每个人都被怀疑的状况下，预备魔女们开始收集对自己有利的<span style="color:#4ade80; font-size:1.1em;">证据</span>，并努力证明自己的<span style="color:#60a5fa;">清白</span>。

# <span style="color:#d4af37; font-size:1.3em; text-shadow: 0 0 10px #d4af37;">游戏目标</span>

![alt text](image.png)

每回合移动并收集证据，将<span style="color:#ef4444; font-size:1.2em; font-weight:bold;">证据</span>、<span style="color:#3b82f6; font-size:1.2em; font-weight:bold;">证词</span>、<span style="color:#ec4899; font-size:1.2em; font-weight:bold;">人心</span>各达到<span style="color:#facc15; font-size:1.4em; text-shadow: 0 0 8px #facc15;">8点</span>，即可宣告<span style="color:#4ade80; font-size:1.3em; text-shadow: 0 0 15px #4ade80;">胜利</span>


# <span style="color:#d4af37; font-size:1.3em; text-shadow: 0 0 10px #d4af37;">移动</span>
![alt text](image-1.png)
每一个回合，系统会随机出<span style="color:#f97316; font-size:1.1em;">2-4小轮</span>，并发给玩家<span style="color:#60a5fa;">小轮数量+1</span>的手牌。每一个小轮玩家依次按照顺位进行如下操作：

1. <span style="color:#a855f7;">打出一张手牌</span>，然后移动相应步数。
2. 移动到格子上<span style="color:#4ade80;">触发格子效果</span>，收集到证据或者删除自己的一个证据

当本回合结束后，进入下一回合，并<span style="color:#facc15;">重新随机</span>所有格子的效果。

# <span style="color:#d4af37; font-size:1.3em; text-shadow: 0 0 10px #d4af37;">格子</span>

![alt text](image-2.png)
格子有以下三种：
1. <span style="color:#4ade80; font-size:1.15em; font-weight:bold;">现场</span>： 获得一个证据 ![alt text](image-3.png)
2. <span style="color:#60a5fa; font-size:1.15em; font-weight:bold;">地下室</span>： 从三个随机证据中获得一个证据，或者不选 ![alt text](image-4.png)
3. <span style="color:#f472b6; font-size:1.15em; font-weight:bold;">娱乐室</span>： 删除至多自己的一个证据 ![alt text](image-5.png)

> ⚠️ <span style="color:#facc15;">注意</span>： 本回合被踩过的格子<span style="color:#ef4444;">不可以</span>再次被任何人触发

# <span style="color:#ef4444; font-size:1.3em; text-shadow: 0 0 15px #ef4444, 0 0 30px #ef4444;">魔女化</span>

![alt text](image-11.png)
角色会因为<span style="color:#f97316;">证据的量</span>、<span style="color:#ec4899;">交锋失败</span>和<span style="color:#a855f7;">魔法带来的精神压力</span>等方式增加魔女化。一旦角色魔女化进度条达到<span style="color:#ef4444; font-size:1.3em; font-weight:bold; text-shadow: 0 0 10px #ef4444;">100%</span>，将会触发魔女化。
![alt text](image-12.png)
魔女化后，角色将在<span style="color:#ef4444; font-weight:bold;">下一个回合结束后被处刑</span>。期间角色仍然可以搜集证据，可以赶在被处刑前宣告胜利。
![alt text](image-13.png)
<span style="color:#a855f7; font-size:1.2em; text-shadow: 0 0 10px #a855f7;">魔女化会大幅强化角色的魔法。</span>

1. 施法会受到魔女化惩罚，依据角色而变
2. 交锋失败会受到5点魔女化惩罚
3. 每一回合结算时，将会给角色造成证物、证词、人心点数之和的魔女化惩罚
4. 每一个小轮结束后，超出8点上上限部分的证物、证词、人心将会额外对角色造成魔女化惩罚


# <span style="color:#a855f7; font-size:1.3em; text-shadow: 0 0 15px #a855f7, 0 0 25px #a855f7;">魔法</span>
每个角色都有自己的<span style="color:#a855f7; font-size:1.1em;">魔法</span>。魔法可以在可以发动时发动，但是要注意，<span style="color:#ef4444;">魔法发动会增加角色的压力</span>，从而促进魔女化。

# <span style="color:#f97316; font-size:1.3em; text-shadow: 0 0 15px #f97316, 0 0 25px #f97316;">交锋</span>
当两名或以上玩家在移动的时候<span style="color:#facc15; font-size:1.1em;">擦肩而过</span>，将会触发交锋。
![alt text](image-8.png)
交锋时，所有玩家观察屏幕上的<span style="color:#4ade80; font-size:1.1em;">指示灯</span>。当指示灯亮后，<span style="color:#60a5fa; font-size:1.15em; font-weight:bold;">点击屏幕</span>。反应最快的玩家将获得<span style="color:#d4af37; font-size:1.2em; text-shadow: 0 0 8px #d4af37;">胜利</span>。
![alt text](image-9.png)

结算时，除了<span style="color:#d4af37; font-size:1.1em;">第一名</span>之外的所有角色都会因为精神压力受到<span style="color:#ef4444; font-size:1.1em;">5点魔女化</span>，然后从第一名开始，依次<span style="color:#f97316; font-size:1.15em; font-weight:bold;">抢夺下一名的一个证物</span>。
